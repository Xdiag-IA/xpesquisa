API local

Contrato versionado em OpenAPI JSON. Esta página funciona sem CDN ou serviços externos.

Iniciar uma pesquisa

POST /api/research · Content-Type: application/json

{"question": "Qual a evidência sobre elastografia hepática?", "limit": 8}

Retorna 202 com id. Campo query opcional substitui a estratégia automática. Limite de 1 a 20 artigos e duas pesquisas simultâneas.

Consultar e exportar

  • GET /api/health — saúde e provider ativo.
  • GET /api/research — últimas 50 pesquisas.
  • GET /api/research/{id} — status, fontes, evidências, afirmações e eventos.
  • GET /api/research/{id}/export — metadados e vínculos sem textos científicos.

Estados: queued, running, completed, failed. Consulte a cada 1,5 segundo até completed ou failed. Falhas ficam preservadas no histórico.

Limites do contrato

API experimental, sem autenticação, apenas para loopback. Respostas incluem dados científicos não revisados. completed significa execução terminada, nunca validação clínica. Schema 0.1.0; exportação reduzida não é um arquivo Run importável.
